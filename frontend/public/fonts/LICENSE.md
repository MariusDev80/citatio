# Fonts — licensing

Both families are self-hosted (no Google Fonts runtime call) and redistributed
under the SIL Open Font License 1.1, which permits bundling and web embedding.

| File | Family | Licence |
|------|--------|---------|
| `instrument-serif-400.woff2` | Instrument Serif Regular — Rodrigo Fuenzalida & Jordan Egstad | SIL OFL 1.1 |
| `instrument-serif-400-italic.woff2` | Instrument Serif Italic — idem | SIL OFL 1.1 |
| `geist-var.woff2` | Geist Variable (400–600) — Vercel | SIL OFL 1.1 |

All three are the `latin` subset (U+0000–00FF plus common punctuation), which
fully covers French — including the accented vowels, `ç`, and the `œ` ligature.
Non-Latin text falls back to the stacks declared in `styles.css`.
